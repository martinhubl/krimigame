# KRIMIGAME

A turn-based multiplayer deduction web game built around a custom PHP MVC backend.

## Overview

KRIMIGAME is a web application focused on multiplayer game flow, server-side state management, validation, and reliable backend behavior.

The project includes:

- room and player flows
- server-side game state
- movement validation
- turn handling
- clues and win conditions
- JSON endpoints
- administration features

## Tech stack

- PHP
- SQL / PDO
- HTML
- CSS
- JavaScript
- JSON APIs

## Engineering focus

- custom MVC-style backend architecture
- domain services and routing policies
- authentication and session controls
- CSRF protection
- API input validation
- database-backed game logic
- clear HTTP error handling
